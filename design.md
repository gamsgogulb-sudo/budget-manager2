# MoMoney Design System

## 1. Aesthetic Recipe: "Clean Professional & Trusted Finance"
- **Vibe**: 신뢰감 있는, 정돈된, 현대적인 금융 서비스 인터페이스.
- **Mood**: Minimalist with vibrant accent colors for data visualization.

## 2. Typography
- **Primary**: 'Inter', sans-serif (UI 요소)
- **Data/Display**: 'Outfit', sans-serif (금액 및 대시보드 수치)
- **Mono**: 'JetBrains Mono' (계좌 번호, 데이터 코드)

## 3. Color Palette
- **Primary**: Blue-600 (#2563eb) - 신뢰와 전문성
- **Secondary**: Indigo-500 (#6366f1)
- **Spending/Expense**: Rose-500 (#f43f5e)
- **Income**: Emerald-500 (#10b981)
- **Background (Light)**: Gray-50 (#f9fafb)
- **Background (Dark)**: Slate-950 (#020617)

## 4. Components & Layout
- **Layout**: Minimalist navigation with efficient whitespace management.
- **Cards/Containers**: Rounded corners standardized to `rounded-xl` (12px) or `rounded-2xl` (16px).
- **Lists**: Pure and clean backgrounds without containing boxes to maximize data density.
- **Charts**: Integrated seamlessly into summary sections.
- **Animations**: Smooth state transitions with subtle feedback.

## 5. Interaction Guidelines
- 버튼 호버 시 밝기 변화 또는 미세한 크기 확대 (`motion`)
- 로딩 상태 시 Skeleton Screen 사용
- 다크 모드 전환 시 매끄러운 트랜지션 효과
